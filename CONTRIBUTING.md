# Contributing to LogLog Viewer

Thank you for your interest in contributing to LogLog Viewer.

## How to Contribute

### Reporting Bugs

Create an issue including:

- Device model
- Android version
- App version
- Description
- Steps to reproduce
- Screenshots

### Suggesting Features

Open an issue with:

- Feature description
- Use case
- Expected behavior

### Pull Requests

1. Fork the project.
2. Create a branch.
3. Make changes.
4. Test changes.
5. Submit Pull Request.

## Coding Guidelines

- Use Kotlin style conventions.
- Keep code readable.
- Add comments where necessary.
- Test before submitting.
